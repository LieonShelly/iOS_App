
以下是一个帮助用户戒断强迫症的一个App。用户在关门时总是由于强迫症总是纠结门是否已经关好，所以想做一个App来帮助用户缓解强迫症。我希望你根据一下提示词，使用html生成对应的ui界面，生成的css文件放到单独的css目录中，整个界面的尺寸使用iPhone14的尺寸

# Prompt 1：主界面（首页）
- 目标：提供“确认按钮”，并显示当天确认次数
- 设计一个移动应用的主界面，帮助用户减少强迫性确认行为。界面风格简洁，采用柔和的蓝色或绿色背景，让用户感到放松。
- 主要元素：
  - 一个 **大大的确认按钮**（强调用户只需要按一次）
  - 一个 **今日确认次数统计**（比如“今日确认 3 次”）
  - 一个 **倒计时提醒组件**（如果用户刚确认过，显示“请等待 5 分钟”）
  - 一个 **数据趋势按钮**，让用户查看自己减少确认的进步
  - UI 风格：极简风，圆角设计，避免复杂动画

#  Prompt 2：确认反馈界面
- 目标：让用户“确认一次后就安心离开”
- 设计一个移动应用的“确认反馈”页面，帮助用户减少反复确认门是否关好。
- 用户点击“确认按钮”后，进入这个页面：
  - **大大的“门已关好！”提示**
  - **10秒倒计时**（引导用户等待倒计时结束后离开）
  - **拍照确认功能**：
    - **拍照按钮**（允许用户拍下门锁状态）
    - **最近一次确认照片**（仅允许查看1次）
  - **语音提示按钮**（点击后播放“你已经确认过了”）
  - **返回首页按钮**
  - **UI 细节**：
    - 照片区域以卡片形式展示，避免影响主要界面布局
    - 轻微呼吸动画增强反馈感
    - 使用柔和的蓝色或绿色渐变，减少焦虑感


 # Prompt 3：数据统计界面
-  目标：让用户看到自己的进步，增强信心
- 设计一个“数据统计”页面，帮助用户追踪自己减少强迫确认的进展。
- 主要内容：
  - **今日确认次数**
  - **最近7天的确认次数折线图**
  - **今日是否完成“仅确认1次”挑战**
  - **正向反馈：“你比上周减少了 30% 的确认次数，继续加油！”**
  - 风格简约，使用蓝色、绿色渐变，让数据易读
