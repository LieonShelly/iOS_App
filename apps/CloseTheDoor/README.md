# Close The Door - 帮助减少强迫性确认行为

这是一个帮助用户减少强迫性确认行为的移动应用。该应用旨在帮助那些在关门时总是担心门是否关好的用户，通过提供确认机制和反馈，帮助用户逐渐减少反复确认的行为。

## 功能特点

- **确认按钮**：用户只需按一次确认按钮，记录确认行为
- **倒计时提醒**：确认后显示倒计时，引导用户等待一段时间再确认
- **拍照确认**：允许用户拍下门锁状态，作为确认的辅助证据
- **语音提示**：提供语音反馈，增强确认感
- **数据统计**：追踪用户的确认次数，展示进步趋势

## 页面说明

1. **主界面（首页）**
   - 大大的确认按钮
   - 今日确认次数统计
   - 倒计时提醒组件
   - 数据趋势按钮

2. **确认反馈界面**
   - "门已关好！"提示
   - 10秒倒计时
   - 拍照确认功能
   - 语音提示按钮
   - 返回首页按钮

3. **数据统计界面**
   - 今日确认次数
   - 最近7天的确认次数折线图
   - 今日是否完成"仅确认1次"挑战
   - 进步反馈信息

## 技术实现

- 使用HTML5、CSS3和JavaScript构建
- 适配iPhone 14尺寸（390px × 844px）
- 使用localStorage存储用户数据
- 使用Chart.js绘制数据图表
- 使用Web API实现拍照和音频功能

## 使用方法

1. 打开应用，在主界面点击"确认"按钮
2. 在确认反馈界面，可以拍照记录门锁状态
3. 等待倒计时结束，或使用语音提示功能
4. 返回首页，查看今日确认次数
5. 点击"查看数据趋势"按钮，了解自己的进步情况

## 设计理念

- 简洁明了的界面设计，减少视觉干扰
- 柔和的蓝色和绿色配色，营造放松的氛围
- 圆角设计元素，增加友好感
- 轻微动画效果，增强交互体验

## 注意事项

- 应用需要相机和麦克风权限才能使用拍照和语音功能
- 数据存储在本地，清除浏览器数据会导致历史记录丢失
- 建议每天只确认一次，逐渐减少确认频率
